# Video Agent

AI-powered video meeting assistant built with Python, Streamlit, LangChain, and Groq.

## Features

- Download or ingest video/audio sources
- Transcribe meeting audio
- Summarize transcript content
- Extract action items, decisions, and questions
- Use a retrieval-augmented generation flow for Q&A over meeting content

## Run locally

1. Create and activate a virtual environment.
2. Install dependencies:
   pip install -r requirements.txt
3. Start the app:
   streamlit run app.py

## Environment

Create a local `.env` file with your API keys and settings. Do not commit secrets.
